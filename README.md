# Git Engineering Workflow Lab

A practical Git reference for backend developers working in team environments.

## Core workflow
```text
Working Tree -> Staging -> Commit -> Feature Branch -> Pull Request -> CI -> Review -> Merge
```

## Topics
- Branching strategies
- Meaningful commits
- Pull requests
- Rebase vs merge
- Conflict resolution
- Cherry-pick
- Revert vs reset
- Tags and releases
- Reviewing diffs
- CI checks
- Secret safety

## Backend developer checklist
- Never commit passwords, API keys or tokens.
- Keep commits focused.
- Review the diff before pushing.
- Prefer small pull requests.
- Resolve conflicts carefully.
- Run tests after conflict resolution.

This repository is a learning reference for professional Git workflows.
